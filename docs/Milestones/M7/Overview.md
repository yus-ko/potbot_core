## 2. 発見された問題

### 症状

`docker compose up -d` で rosbag 解析パイプラインを起動し、ゴール位置を (-1.25, 3.5) に設定すると、`/plan` トピックのグローバルパスがループ状に乱れる。

### 根本原因

**原因 1: APF フィールドサイズが固定で小さすぎる（主因）**

`apf_planner.cpp` でフィールドが固定 50×50 セル（0.05m × 50 = 2.5m）で生成される。ゴール (-1.25, 3.5) は Y 方向に 3.5m 必要だが、フィールド範囲は ±1.25m のため**ゴールがフィールド外**に出る。

- `setGoal(-1.25, 3.5)` では `getFieldIndex()` が例外を投げ、`IS_AROUND_GOAL` フラグが設定されない
- 経路探索の終端判定 `IS_AROUND_GOAL == false` が常に真となり、経路が最大点数（100点）まで生成され続ける
- ローカル最小値解消コードが障害物エッジを追跡し続け、経路がループ状になる

**原因 2: `getSquareIndex` の `size_t` アンダーフローバグ（副因）**

`field.cpp` の `getSquareIndex` で `size_t centor_row - range` がアンダーフローし、フィールド端でサーチが空になって経路が途中で打ち切られる。また、1セルでも範囲外の場合に全結果をクリアしていた。
